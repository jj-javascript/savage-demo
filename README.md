## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/savage-demo.git
````

2. Navigate to the project directory:

```bash
cd savage-demo
```

3. Install Dependencies:
```bash
npm install
```
4. Start the server:
```bash
npm run dev
```
5. Open your browser and go to:
```bash
http://localhost:3000
```

## Usage
1. Create messages to post to messageboard.
2. View and up/downvote other messages.
3. Delete messages.
